# Session Log - Feb 21, 2026

## Summary of Work
Today's session focused on connecting the Flutter mobile app to the FastAPI backend and resolving synchronization issues.

### Key Achievements
1.  **Flutter SQLite Integration**: The app successfully uses SQLite to cache the [Contacts](file:///home/finch/repos/tawag-tugon-api/tawag_tugon_app/lib/db_helper.dart#55-60) payload.
2.  **Debugging Sync Flow**: Identified and fixed a data structure mismatch between the Flutter app (which expected a direct list) and the API [manifest](file:///home/finch/repos/tawag-tugon-api/app/api/v1/public.py#12-34) endpoint (which returns `{"contacts": [...]}`).
3.  **Targeted Seeding**: We created [seed_qc.py](file:///home/finch/repos/tawag-tugon-api/seed_qc.py) to inject the specific "qc" tenant and emergency contacts needed by the app.
4.  **Schema Versioning**: We learned that Flutter `sqflite` requires the app storage to be cleared when changing column definitions (like `tenant_id` and `protocol`) unless a migration is written.
5.  **Device Connection Script**: Created [tawag_tugon_app/connect_device.sh](file:///home/finch/repos/tawag-tugon-api/tawag_tugon_app/connect_device.sh) to automate the `adb tcpip` and `adb connect` flow for physical device testing over Wi-Fi.

6.  **Scraper Service Implemention**: Created `ScraperService` using `httpx` and `beautifulsoup4` to fetch external LGU news pages.
7.  **Scraper API Endpoint**: Added a new protected `POST /api/v1/lgu/scrape` endpoint for admins to manually trigger the scraping of a URL and save it to their tenant's `News` table.
8.  **JWT Authentication Enforcement**: Updated the login endpoint to properly hash and verify passwords using `passlib` and `bcrypt`. Fixed a `passlib` compatibility bug by downgrading `bcrypt` to `4.0.1`.

### Important Commands for Local Testing
To ensure the physical phone can talk to the backend over the local network:
1.  **Connect Device**: [./tawag_tugon_app/connect_device.sh](file:///home/finch/repos/tawag-tugon-api/tawag_tugon_app/connect_device.sh) (or manually run `adb tcpip 5555` followed by `adb connect 192.168.1.96:5555`)
2.  **Start API**: `uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload` (binding to `0.0.0.0` instead of `127.0.0.1` is critical).

9.  **Flutter News Sync Implementation**: Implemented an offline-first sync architecture in the Flutter app to fetch news from `GET /api/v1/public/qc/news` and store it in a newly created `news` SQLite table.
10. **Dynamic IP Automation**: Upgraded the `connect_device.sh` script to automatically extract the laptop's Wi-Fi IP address using `hostname -I` and generate a `lib/env.dart` file, eliminating hardcoded IPs.
11. **True Archive (Swipe-to-Dismiss)**: Implemented a robust SQLite "True Archive" solution. Upgraded the SQLite schema to v3 with an `is_archived` column, refactored the sync logic to UPSERT (preserving local archive state), and wired a `Dismissible` widget to soft-delete articles from the News feed locally.
12. **News Detail Screen**: Created a local Flutter UI (`NewsDetailScreen`) that displays the full text of scraped articles directly from the offline SQLite cache, alongside an action button to open the original source URL.
